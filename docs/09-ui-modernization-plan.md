# 09 · 界面现代化实施计划（用户 7 项建议清单落地）

## 当前原生实现与设计参考

用户已选择 **Tauri 2 + React/TypeScript**；Rust 首批只迁移配置与预设。界面保留产品功能和安全语义，不保留旧 WinForms 控件、布局或 Desktop→CLI 的依赖结构。

用户已确定采用 **C 音效台**作为正式前端的设计基线：左侧分类与收藏，中间音效网格，右侧紧凑发送与监听控制，预设和全部静音保持易达。A 工作台、B 单屏控制台仅保留为设计比较资料，不再作为正式布局候选。

正式程序已实现于 `desktop/`：Tauri 原生窗口与托盘、React/TypeScript 音效台、Rust 配置/预设存储，以及独立的 C# 音频后端。真实设备选择、应用绑定、素材导入/重复确认、分组/收藏/详情、试听/发送、热键和诊断均走实际命令链路，不复用预览中的模拟状态。

原生窗口使用 Tern · Stencil 深色分层、克制的紫色强调与可关闭的玻璃效果；收起导航/混音栏及小窗口滚动保留核心按钮可达。版本、构建入口与验证限制见 [README](../README.md) 和 [验证记录 §10](07-validation-and-handoff.md#10-原生音效台局部-rust-迁移的本地验证)。浏览器采集/裁剪仍仅为 P5 计划。

选型阶段的独立 `design-preview/` 保留三种可切换布局，作为设计比较资料：

- **A 工作台**：导航、路由/素材工作区、可收起的属性检查器。
- **B 单屏控制台**：四路控制与完整音效列表，设置和诊断通过面板访问。
- **C 音效台**：分类/收藏、音效网格、紧凑混音栏。

三种布局共用 Tern · Stencil 深色半透明视觉与同一组示例数据。支持搜索、收藏、选择详情、设置面板、键盘增益操作、模拟静音锁存，以及关闭玻璃效果。所有发送默认关闭。

预览不连接真实音频引擎，不枚举设备、不读取音频文件、不注册系统热键、不写入用户设置。它与 `desktop/` 正式程序分离；以下预览证据不能代替原生功能验证。

在仓库根目录启动预览：

```powershell
npm --prefix design-preview ci
npm --prefix design-preview run dev -- --host 127.0.0.1 --port 5327 --strictPort
```

打开 `http://127.0.0.1:5327/`，默认进入已采用的音效台；顶部其他布局仅供设计比较。独立地址参数为 `?layout=workbench`、`?layout=console`、`?layout=soundboard`。截图位于 `design-preview/previews/`。

验证：TypeScript/Vite 构建通过；实际 Chromium 检查三种布局在 1440×1000、1000×760、760×640 下的横向溢出、静音按钮可达性、列表高度、网格操作按钮与播放条边界。另执行搜索/属性联动、设置与诊断面板、Escape 关闭、收藏筛选、试听状态示意、静音/解锁保持全关、0–400% 增益键盘边界和不透明模式检查。以上仅证明设计预览，不证明真实音频行为。

## 阶段 A · 状态系统（清单 1、2、6）

| 项 | 改动 |
| --- | --- |
| A1 大状态条 | 状态摘要区从 6 芯片改为：左侧大圆点 + 大字状态（20px 半粗）+ 副说明 + 4 个小芯片（麦克风/附加音频/监听/音效）。颜色语义：灰=全关、绿=正在发送、琥珀=需要注意（试听中/待配置）、红=故障（紧急锁存/虚拟输出失效）。去掉状态栏里重复的"就绪"字样 |
| A2 措辞统一 | 状态词收敛为：`开 / 关 / 未绑定（灰）/ 设备不可用（红）/ 发送中 / 试听中 / 锁存`。红色只用于故障与紧急静音。落点：`UpdateCards` / `UpdateRouteChip` / `UpdateClipChip` / `DescribeIssues` |
| A3 电平条 | 麦克风卡与音效输出卡加实时电平条（数据源：`SessionMetrics.MixerPeak`，500ms 轮询采样；UI 端峰值保持+衰减平滑）。音效卡空闲时电平条置灰 |
| A4 诊断折叠 | 底部状态栏"峰值/削波/硬跳变/欠载"移入"诊断"按钮弹层；状态栏只保留 相位·设备·热键·故障提示 |

状态判定真值表（全部来自 `SessionStatus`，UI 不伪造）：

| 条件 | 大状态 | 颜色 |
| --- | --- | --- |
| EmergencyLatched | 紧急静音已锁存 | 红 |
| OutputLost | 虚拟输出已失效 | 红 |
| 任一 Mic/Extras/App 发送开启 | 正在对队友发声 | 绿 |
| Clip 试听中 | 正在本地试听 | 琥珀 |
| 设备未校验 | 待配置 | 琥珀 |
| 其余 | 未对队友发声（全关） | 灰 |

## 决策点（需确认）

1. **增益滑块范围**：引擎增益 0–4.0 倍。0–400% 保留全部能力（推荐）；0–100% 与示意稿一致但 >1.0 增益不可调
2. **电平条平滑**：500ms 真实采样 + UI 峰值衰减动画（推荐，视觉平滑且数据真实）；或纯 500ms 步进
3. **实施节奏**：A→E 一次性落地（推荐，工作量集中且 LayoutAudit 全量把关）；或按 A/B、C-E 分两批

## 验收标准

- 构建 0 警告 0 错误；181 项测试全通过（音频层零改动）
- `--selftest` 布局审计：4 DPI × 3 尺寸全通过，断言适配新控件（开关/电平条/行控件）
- GUI 冒烟截图：大状态条四色真值表、开关视觉、音效行三按钮、诊断弹层
- 全部状态文案不出现"就绪"重复；红色仅出现在故障/锁存/Danger 按钮
