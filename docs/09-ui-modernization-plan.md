## 与旧方案的关系

`随声麦_UI重设计方案.md` 的 §5.3 曾写"框架不支持圆角时不要硬模拟"。
本轮用户清单明确要求圆角 8–12px 与扁平按钮，且提供了自绘 ToggleSwitch 示例代码，
**以新清单为准**：引入少量自绘控件（开关/圆角按钮/电平条），样式全部取自 Theme。

## 阶段 A · 状态系统（清单 1、2、6）

| 项 | 改动 |
| --- | --- |
| A1 大状态条 | 状态摘要区从 6 芯片改为：左侧大圆点 + 大字状态（20px 半粗）+ 副说明 + 4 个小芯片（麦克风/附加音频/监听/音效）。颜色语义：灰=全关、绿=正在发送、琥珀=需要注意（试听中/待配置）、红=故障（紧急锁存/虚拟输出失效）。去掉状态栏里重复的"就绪"字样 |
| A2 措辞统一 | 状态词收敛为：`开 / 关 / 未绑定（灰）/ 设备不可用（红）/ 发送中 / 试听中 / 锁存`。红色只用于故障与紧急静音。落点：`UpdateCards` / `UpdateRouteChip` / `UpdateClipChip` / `DescribeIssues` |
| A3 电平条 | 麦克风卡与音效输出卡加实时电平条（数据源：`SessionMetrics.MixerPeak`，500ms 轮询采样；UI 端峰值保持+衰减平滑）。音效卡空闲时电平条置灰 |
| A4 诊断折叠 | 底部状态栏"峰值/削波/硬跳变/欠载"移入"诊断"按钮弹层；状态栏只保留 相位·设备·热键·故障提示 |

状态判定真值表（全部来自 `SessionStatus`，UI 不伪造）：

| 条件 | 大状态 | 颜色 |
| --- | --- | --- |
| EmergencyLatched | 紧急静音已锁存 | 红 |
| OutputLost | 虚拟输出已失效 | 红 |
| 任一 Mic/Extras/App 发送开启 | 正在对队友发声 | 绿 |
| Clip 试听中 | 正在本地试听 | 琥珀 |
| 设备未校验 | 待配置 | 琥珀 |
| 其余 | 未对队友发声（全关） | 灰 |

## 决策点（需确认）

1. **增益滑块范围**：引擎增益 0–4.0 倍。0–400% 保留全部能力（推荐）；0–100% 与示意稿一致但 >1.0 增益不可调
2. **电平条平滑**：500ms 真实采样 + UI 峰值衰减动画（推荐，视觉平滑且数据真实）；或纯 500ms 步进
3. **实施节奏**：A→E 一次性落地（推荐，工作量集中且 LayoutAudit 全量把关）；或按 A/B、C-E 分两批

## 验收标准

- 构建 0 警告 0 错误；181 项测试全通过（音频层零改动）
- `--selftest` 布局审计：4 DPI × 3 尺寸全通过，断言适配新控件（开关/电平条/行控件）
- GUI 冒烟截图：大状态条四色真值表、开关视觉、音效行三按钮、诊断弹层
- 全部状态文案不出现"就绪"重复；红色仅出现在故障/锁存/Danger 按钮
