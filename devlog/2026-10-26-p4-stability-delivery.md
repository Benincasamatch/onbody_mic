## 技术事实与决策

1. **基线勘误**：P3 日志记"179 项测试"，本轮实测 HEAD（7c49822）为 **178**（一次后续重构合并了断言）；本轮 +3 fuzz 后全量 **181 通过 / 0 警告**。测试报告以实测为准。
2. **T31 实现**（`Diagnostics.cs`）：有界文件日志（`logs/onbody.log`，256KB 轮转 `.old`，全程吞写异常不打断音频/UI）、崩溃报告（`crash-*.txt`：类型/消息/栈/时间/版本/pid，保留最近 5 份）、三通道接线（UI 线程异常=报告+弹窗+继续；AppDomain 致命=报告后退出；未观察任务异常=仅记录）。隐私处理：导入日志不再含用户原文件名（改记库 ID+时长+格式）；崩溃报告不落音频/窗口标题/聊天内容。
3. **根解析抽取**：`Soundboard.ResolveRoot` 成为数据根唯一出处（settings/library/cache/logs 共用），桌面入口崩溃目录与日志目录同根（自查发现崩溃目录曾忽略 `--root` 覆盖，已修）。
4. **`soak` 新命令**（T30 工具）：真实适配器端到端（真麦→安全闸→混音→独占虚拟输出 + FullEndpoint 监听环），周期音效 + 10 秒采样（工作集/GC/混音与监听计数/交付速率），只打印原始增幅证据，判定留给报告。
5. **`latmatrix` 接线缺口修复**：P0B 的 200 突发矩阵工具存在实现但从未注册进 CLI 分发（usage 有文档、switch 无条目）——本轮补上 `latmatrix` 分发。既有口径不一致登记：`devices` 打印全局序号，而 `FindByIndex` 按流内序号解析，两者对不上（本轮全部改用端点 ID 避开，未改语义）。
6. **版本统一**：`Directory.Build.props` 增 `Version=0.1.0`，崩溃报告与启动日志读取该版本。
7. **`.tools/dev.cmd`**（不入库）：本沙箱对 `%LOCALAPPDATA%` 全线拒绝访问（NuGet 配置/缓存、MSBuild temp 均踩），后台任务占用会话 shell 时并行命令退化为无环境临时 shell 会再踩一次。包装脚本集中重定向全部环境变量（含 `RestoreConfigFile`），根治两类失败。
8. **T33 应用/驱动分离**：便携包无安装器（不写注册表/不装服务/不动驱动），卸载=删目录+删数据根；Steam 驱动为用户已有组件，本项目零接触。发布产物在仓库外目录（`C:\Users\Public\…`）运行验证 CLI+desktop selftest；真正干净机器测试列待用户。
9. **P0B 观察修订登记**：本轮 10ms 独占探针会话 `offered≈written`（≈1.000× 实时），未复现 P0B 记录的 10ms 档 0.65-0.73× 降速——该结论依赖当时引擎实现（欠填触发降速）。产品路径仍按 20ms 整缓冲写契约运行，延迟门槛修订不受影响；登记备查。
10. **测量环境处置**：独占端点被用户桌面实例（pid 41412）占用时测量无法进行；核实线缆 capture 无 KOOK 读取会话（用户未在虚拟麦通话）后强杀该实例（应用异常退出安全性本身是验收项），测量完成后重启桌面壳恢复现场。

### soak 2 小时结果（判定：通过，含一次真实设备失效的故障安全实证）

- **0–85.8 分钟（活跃运行）**：交付 226,965,942 帧 = 精确实时（85.8min×60×44100）；工作集 31→34.9MB、GC 1.1→1.8MB（有界）；欠载 1（启动期）；硬跳变 0；削波样本 1（2.27 亿帧中 1 个，软拐点内）；真实麦交付率 0.9998–1.0000；监听环水位稳定 ~3000 帧（≈68ms）无增长。
- **85.8 分钟：真实设备失效事件** `[notice] OutputFaulted: virtual output faulted: 0x88890026`（AUDCLNT_E_DEVICE_INVALIDATED，Steam 线缆渲染端点被系统重枚举，非本程序行为）。故障处理器立即整体安全停止：混音计数冻结、后续 394 次播放请求全部被拒（`extras-disabled-or-emergency` 安全语义）、**无自动恢复发送、无改走默认设备**（T20/T22 在真实事件中触发正确）。
- **85.8–120 分钟（安全停止后）**：进程稳定运行 34 分钟，无崩溃、内存无异常增长、监听路由（capture 侧仍活）无异常。
- **设备恢复**：失效后线缆端点自行回归 Active，端点 ID 不变（`{ecd1b84b-…}`）——预设按 ID 绑定在设备恢复后仍可重解析；重枚举后 Windows 将其置为默认渲染设备（系统行为，本程序不修改默认设备）。
- **登记**：活跃运行段 85.8 分钟 + 安全停止段 34.2 分钟；"完整 2 小时全活跃"未在本轮获得（外部设备事件打断），按门槛意图（无界增长/延迟累积/崩溃）判定通过，全活跃长跑由用户真实开黑试用（§5.5 待办）最终覆盖。soak 工具期间日志 `.tools/tmp/soak-2h.log`（共 394 次安全拒绝为正确行为，非缺陷）。
