# 2026-11-08 左侧导航改为树形目录

## 本轮范围

用户指令：“将应用左侧的音效列表设为树形目录形式。”

现状：左侧侧栏只有“全部音效 / 我的收藏”两个筛选按钮和一个分组列表（嵌套缩进，但没有展开/收起，也没有任何音效条目）。按字面要求落地为**分组 + 音效的目录树**：文件夹可展开，音效条目挂在所属分组下，未分组音效列在树底部。

## 决策

1. **树中包含真实音效**：分组节点下行不再只是子分组，还列出该分组的直接音效；后代音效归属于各自子分组。根级音效单独列在“未分组”分隔行下，该行只是标签，不参与筛选（避免与“全部音效”的 `groupId=null` 语义冲突）。
2. **分组行保持原语义**：点击分组名仍筛选主区（`favoritesOnly=false` + `groupId`），并顺带展开该分组；箭头按钮单独负责展开/收起，`aria-expanded` 同步。分组默认全部展开，收起状态保存在组件内（会话级，不写入设置）。
3. **音效行与卡片交互一致**：单击选中并打开“音效详情与管理”，双击直接发送；多选模式下单击切换选择（Shift 连选），显示勾选块。没有新增“单击即播放”行为，避免误解为对外发送。
4. **信息密度**：音效行显示音频图标、名称（超长省略，`title` 为完整路径）、收藏星标；播放中的音效整行高亮紫色，素材缺失条目降透明度。分组行计数仍为“本组及全部子分组”的音效数。
5. **折叠侧栏**：只保留文件夹图标与顶部两个筛选按钮；音效行、箭头、计数、未分组分隔全部隐藏，避免窄栏中出现一列无意义的音频图标。
6. **窄宽度**：≤700px 时顶部按钮横向换行、树仍然在下方纵向显示（真实窗口 `minWidth=760`，该断点仅用于浏览器预览）。

## 工程成果

- `desktop/src/components.tsx`
  - `GroupNavigation` 重写为树：`collapsed` 集合控制展开状态；遍历 `groupTree` 渲染分组，按 `clip.groupId` 建立直接音效映射；新增 `edit` 回调参数传入音效详情。
  - 子分组先于本组直接音效渲染（文件夹在前、文件在后），未分组音效追加在树底部。
- `desktop/src/App.tsx`：`<GroupNavigation edit={clip => { setClipEditing(clip); setPanel('clip'); }} />`，侧栏 `nav` 的无障碍名称改为“音效目录”。
- `desktop/src/styles.css`
  - 原 `.category-nav button` 全部收窄为 `.category-nav > button`，避免树内按钮继承卡片外观；新增 `.tree-group-row / .tree-toggle / .tree-caret / .tree-label / .tree-clip / .tree-section-label`，使用 `--tree-depth` 控制缩进（每级 13px，音效行额外 +19px 与文件夹文字对齐）。
  - 箭头用 `transform: rotate(-90deg)`（收起，指向右）↔ `rotate(0)`（展开，指向下）；折叠侧栏、≤950px、≤700px 规则同步调整。

## 已知限制

- 未在真实 Tauri 窗口复测：本轮仅改前端，验证使用 Edge headless + Tauri IPC 桩（与 0.5.0/批量导入两轮相同的限制）；Rust/后端零改动。
- 树默认全部展开；音效量很大时侧栏会较长，依赖侧栏滚动。未提供“全部收起”按钮或持久化展开状态。
- 树不随搜索/收藏筛选变化（目录始终显示完整库），仅在筛选分组时高亮对应文件夹。
- 分组名与音效名在 184px（≤950px 为 132px）宽度下按省略号截断，悬停才显示完整路径。

## 下一步

- 音效行可考虑“拖到分组上移动”的拖放操作，需先确认与现有 `clip_group` 命令的一致语义。
