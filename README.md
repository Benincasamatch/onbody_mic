# Onbody Mic

面向游戏语音的可控音频面板：将选定应用的声音、导入音效和真实麦克风组合后，送入语音软件可选择的虚拟麦克风，同时提供独立本地监听。

## 获取与运行

**便携包（推荐）**：下载 [OnbodyMic-0.1.1-portable-x64.zip](https://github.com/Benincasamatch/onbody_mic/releases/download/v0.1.1/OnbodyMic-0.1.1-portable-x64.zip)（[发布页](https://github.com/Benincasamatch/onbody_mic/releases/tag/v0.1.1)），解压到任意可写目录，双击 `OnbodyMic.Desktop.exe`。自包含，无需安装 .NET，不写注册表、不装服务、不动音频驱动；卸载 = 删目录 + 删数据目录（默认 `%LOCALAPPDATA%\OnbodyMic`）。包内附 `开始使用.txt`、`使用说明.md`、`依赖与许可证.md`。

前置条件：Steam 客户端自带的 Streaming Speakers（虚拟音频线缆）已安装——本项目不捆绑也不分发该驱动。

> **队友听不到你说话？** 干净机器上虚拟麦 Capture 端点默认是「已禁用」状态（Windows/Steam 的默认行为）。主窗口顶部会提示，按提示打开「设备设置…」点「启用选中端点」即可；也可用 `OnbodyMic.Cli.exe devices --all` 查看端点状态后 `enable --id <端点ID>`。

**从源码构建**：

```bat
dotnet build OnbodyMic.sln -c Release
dotnet test  OnbodyMic.sln -c Release
```

**重新生成便携包**（发布自包含产物 + 包内文档 + 包自检 + 打 zip）：

```powershell
powershell -ExecutionPolicy Bypass -File build/build-portable.ps1
```

产物：`dist/win-x64/` 与 `dist/OnbodyMic-<版本>-portable-x64.zip`（`dist/` 不入库）。脚本会先对发布产物运行 `--selftest`（含多 DPI 布局审计），失败即中止，不会产出未经验证的包。

**自检**：

```bat
OnbodyMic.Desktop.exe --selftest
```

覆盖桌面壳构建、会话状态快照，以及 96/120/144/192 DPI × 三种窗口尺寸的布局审计（无裁切、无越界、紧急按钮可见、卡片列数符合响应式规则）。

## 已采用的默认行为

- 首发一个应用 + 一个真实麦克风 + 一条短音效；新音效替换旧音效，同一条再次触发从头重播。
- 启动恢复最后预设，但发送与监听全部关闭；每次应用预设也先关闭并清空旧音频，再由用户启用。
- 默认监听偏好为“仅音效”，另提供“实际虚拟麦克风”监听；两种模式互斥，启动均不自动开启。
- 音效复制到受管本地库，原文件不改；收藏、多预设、基础搜索/分组与热键纳入首发。
- 热键初始不绑定，用户主动设置并验证；紧急全静音保持锁定，解除后也不会自动恢复发送。
- 具体浏览器、播放器、设备、游戏与软件版本仍待 P0 采集；不把测试建议当成用户实际配置。

## 先读这些注意事项

1. 本程序的防误传控制只覆盖自身音频路径。其他应用直接写入共享虚拟线、KOOK 自行换输入或麦克风拾取扬声器声音，不能由本程序绝对阻止。
2. 捕获浏览器可能包括其他标签页声音；不要把网页 KOOK 与待捕获音乐放在同一个浏览器捕获范围内。
3. KOOK 的按键说话、降噪和增益可能影响音效；本地监听不等于队友最终听感。
4. 驱动安装、系统设置、正式发布和软件开发不包含在本次文档授权中；未来实施需明确操作范围。
